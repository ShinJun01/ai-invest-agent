## 4개 레이어 (책 전체 구조)

1. **도구 세팅** (2장) — Claude Cowork 설치, 유료 플랜, 폴더/워크스페이스 구성.
   컴퓨터 파일에 직접 접근하는 "동료"로 기능하기 위한 밑작업.
   → `01_tool_setup/`

2. **시장 분석** (3장) — 미국 시장(나스닥) 마감 데이터로 코스피 방향 예측.
   나스닥-코스피 연동 패턴, VIX/환율 신호, 섹터별 움직임.
   → `02_market_analysis/`

3. **기술지표 결합** (4장) — 거시(시장 상황) + 미시(기술지표)를 결합해 매매 신호 정교화.
   RSI, MACD, 볼린저밴드 조합, 가짜 신호 필터링.
   → `03_technical_indicators/`

4. **자동 실행과 검증** (5~6장) — 키움증권 OpenAPI로 실제 매수/매도 자동화,
   백테스팅으로 전략의 승률/성과를 숫자로 검증.
   → `04_auto_execution_backtest/`
