# 거시 + 미시 결합 판단 로직 (4장 반영)

거시 분석(시장 전체 방향, [[../02_market_analysis/판단로직.md]])은 "오늘 시장에 들어갈지 말지"를 정하는 큰 필터,
미시 분석(개별 종목 기술지표)은 "지금이 좋은 타이밍인지"를 정하는 도구. 두 가지가 같은 방향일 때가 가장 신뢰도 높은 신호다.

## 점수제 (5점 만점)

| 조건 | 배점 |
|---|---|
| 나스닥 상승 | +1 |
| VIX 20 미만 | +1 |
| 원달러 환율 하락(원화 강세) | +1 |
| RSI(14) 30~65 구간(중립) | +1 |
| MACD 골든크로스 | +1 |

거시 3점(나스닥/VIX/환율) + 기술지표 2점(RSI/MACD) = 총 5점 만점으로 구성이 나뉜다.

## 판단 규칙 (기본 총점 규칙)

- **총점 4~5점**: 매수 신호
- **총점 2~3점**: 관망
- **총점 0~1점**: 매도

## 신호 충돌 처리 — 우선순위 계층(Priority Hierarchy) + 거부권(Veto)

원칙: **거시 우선**. 시장 전체가 강하게 나쁠 때는 종목 기술지표가 아무리 좋아도 진입하지 않는다. 아래를 기본 총점 규칙보다 먼저 적용한다.

1. **거시 점수(나스닥·VIX·환율 3점 만점) ≤ 1점** → 기술지표 점수와 무관하게 오늘은 매수하지 않는다 (관망)
2. **거시 점수 = 3점(만점)이고 기술지표 점수(RSI·MACD) ≤ 1점** → 소량(평소 포지션의 절반)만 진입
3. 위 1, 2에 해당하지 않으면 기본 총점 규칙(4~5 매수 / 2~3 관망 / 0~1 매도)을 그대로 적용
4. **거부권(Veto)**: 목표 종목 RSI가 **80을 초과**하면, 총점이나 우선순위 계층 결과와 무관하게 매수를 절대 금지한다 (초과열 상태에서 물리는 것을 원천 차단)

이 네 규칙이 점수 합산보다 항상 우선한다 — "거시 흐름을 먼저 믿되, 종목 상태가 최악(RSI 80 초과)이면 시장이 좋아도 멈춘다."

## 신호 상충 시 참고 예시

거시는 긍정적인데 RSI가 이미 70~78 이상(과매수)인 상충 상황이면, 위 거부권 기준(80 초과)에는 안 걸리더라도 아래 세 가지 대응 중 하나를 사전 규칙으로 택해 일관되게 적용한다 (그때그때 감정적으로 결정하지 않음):

1. 진입하지 않고 관망
2. 진입하되 평소보다 작은 수량으로 진입
3. RSI가 70 아래로 내려올 때까지 대기 후 진입

## 예시 (책 인용 시나리오)

- 나스닥 +1.2%, VIX 18, 환율 소폭 하락, RSI 45(중립), MACD 골든크로스 → 5점 만점 중 5점 → 매수 신호, 상대적으로 안전한 진입
- 나스닥 상승했지만 RSI 78(과매수) → 거시는 긍정, 미시는 경고 → 점수제상 RSI 조건 미충족(0점)이므로 총점이 낮아지고, 위 세 가지 대응 옵션 중 사전 규칙 적용
