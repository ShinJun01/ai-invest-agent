# 매매전략 생성 프롬프트 설계 (4장 "프롬프트 설계" 반영)

책이 제시한 3원칙을 그대로 적용한다.

## 원칙 1 — 분석 순서를 명확히 지정
1. 미국 시장 방향 확인 (나스닥/S&P500/다우 등락률)
2. VIX와 환율 판단
3. 목표 종목 RSI·MACD 확인
4. 종합 점수 산출
5. 매수/관망/매도 결론 도출

## 원칙 2 — 판단 기준을 수치로 구체화 (애매한 형용사 금지)

| 조건 | 수치 기준 | 점수 |
|---|---|---|
| 나스닥 상승 | 전일 대비 상승 | +1 |
| VIX | 20 미만 | +1 |
| VIX 고위험 기준 | 25 이상 = 고위험 (참고용, 감점 아님) | - |
| 원달러 환율 | 전일 대비 하락(원화 강세) | +1 |
| 목표 종목 RSI(14일) | 30~65 구간 | +1 |
| 목표 종목 MACD | 골든크로스 상태 | +1 |

- 총점 4~5점: 매수
- 총점 2~3점: 관망
- 총점 0~1점: 매도

(※ 03_technical_indicators/점수제_판단로직.md의 "RSI 30~60"은 이번 4장 실제 예시 프롬프트의 "RSI 30~65"로 갱신·통일한다.)

## 원칙 3 — 결과물 형식을 고정

```
[거시 판단]:
[기술지표 판단]:
[종합 점수 N/5]:
[최종 결론]:
[근거 한 줄]:
```

## 실전 프롬프트 원문 (책 예시, 목표 종목만 치환 가능)

> 오늘 날짜 기준으로 다음을 분석해줘. 먼저 어제 나스닥·S&P500·다우 등락률과 VIX, 원달러 환율을 검색해. 나스닥 상승이면 +1점, VIX 20 미만이면 +1점, 환율 하락이면 +1점이야. 그다음 [목표 종목]의 14일 RSI와 MACD 현황을 확인해. RSI 30~65 구간이면 +1점, MACD 골든크로스 상태면 +1점이야. 총점 기준으로 4~5점이면 매수, 2~3점이면 관망, 0~1점이면 매도로 결론 내줘. 결과는 AI투자에이전트/매매전략 폴더에 오늘 날짜로 저장해줘.

- 기본 목표 종목: 삼성전자 (책 예시). 이후 02_market_analysis에서 뽑히는 "오늘의 집중 섹터" 대표 종목으로 확장 가능.
- 프롬프트는 일회용이 아니라 튜닝하며 성장시키는 것 — 기준 수치(20, 25, 30~65 등)는 운용하면서 조정해나간다.
