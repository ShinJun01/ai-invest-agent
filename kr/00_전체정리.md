## 레이어 2 — 시장 분석 (3장)

"나스닥 방향 = 코스피 방향" 같은 단순 공식은 오판 위험이 크다는 게 책의 핵심 주장. 아래 지표들을 종합해서 판단하도록 설계함 (`02_market_analysis/판단로직.md`).

**지수 전체 판단용 4개 지표**
1. 나스닥/S&P500/다우 등락률 — 1차 참고치, 단독 신뢰 금지
2. VIX / VKOSPI — VIX 20 미만 안정, 20 아래→25 돌파 시 "비상 경보", VIX+VKOSPI 동반 급등 시 관망
3. 원/달러 환율 — 상승(원화 약세)=외국인 이탈, 하락(원화 강세)=유입. 지지선/저항선 추적
4. 코스피200 야간 선물(CME) — 개장 전 예고편. 나스닥 상승+야간선물 하락이면 나스닥 신호 무효화

**섹터별 연동 패턴** — 지수 전체와 별개로 "오늘 집중 섹터"를 뽑음
- 엔비디아/AMD/마이크론(반도체, SOX) 강세 → 삼성전자·SK하이닉스 주시
- 테슬라/리비안(EV) 약세 → LG에너지솔루션·삼성SDI·포스코퓨처엠(2차전지) 관망
- 애플 밸류체인 → LG이노텍 등 부품주
- MS/구글/메타(빅테크 SW) 강세 → 네이버·카카오

**자동화 현황**: 매일 07:00(KST) 스케줄 작업이 위 로직으로 브리핑을 생성해 `AI투자에이전트/미국시장분석/YYYYMMDD_미국시장분석.txt`로 저장·전달 (스케줄 작업 ID: `trig_01KDGfDGzffFZfYFkG1o4hKf`, 이름: "미국 증시 마감 브리핑").
- 8/20 실제 실행 예시: 미국 3대 지수 소폭 반등(+0.2%대), VIX 14.89(-6%), 원달러 1,397.7원. 전일 코스피는 -5.80% 급락(매도 사이드카 발동) 상황이었음.

## 레이어 3 — 기술지표 결합 (4장)

거시(시장 전체, 진입 여부의 큰 필터) + 미시(개별 종목 기술지표, 타이밍 도구)를 결합. (`03_technical_indicators/점수제_판단로직.md`, `매매전략_생성_프롬프트.md`)

**점수제 (5점 만점)**: 나스닥 상승 +1 / VIX 20 미만 +1 / 환율 하락 +1 / RSI(14) 30~65 +1 / MACD 골든크로스 +1
- 거시 3점 + 기술지표 2점으로 구성 분리

**기본 총점 규칙**: 4~5점 매수 / 2~3점 관망 / 0~1점 매도

**신호 충돌 처리 — 우선순위 계층 + 거부권** (거시 우선 원칙)
1. 거시 점수 ≤1점 → 기술지표 무관하게 매수 금지
2. 거시 점수 만점(3)인데 기술지표 ≤1점 → 소량(절반) 진입
3. 그 외엔 기본 총점 규칙 적용
4. **거부권(Veto)**: RSI 80 초과 시 총점·우선순위 무관 매수 절대 금지

**프롬프트 설계 3원칙** (책 예시 그대로 적용)
1. 분석 순서 명시 (미국시장→VIX/환율→RSI/MACD→점수→결론)
2. 판단 기준 수치화 (형용사 금지, "VIX 25 이상 = 고위험"처럼)
3. 출력 형식 고정: `[거시 판단]:` `[기술지표 판단]:` `[종합 점수 N/5]:` `[최종 결론]:` `[근거 한 줄]:`

**자동화 현황**: 같은 07:00 스케줄 작업이 기본 목표 종목 **삼성전자** 기준으로 매매전략 파일도 함께 생성 → `AI투자에이전트/매매전략/YYYYMMDD_매매전략.txt`

## 레이어 4 — 자동 실행과 검증 (5~6장)

책 내용: 증권사 API 연결 → 실시간 시세 → 백테스팅 → 매매 스타일(모멘텀/회귀/돌파) 선택 → 손절/익절(트레일링 가능) 필수 설정 → 매매 전 백테스팅 → 주 1회 Cowork 점검 → 3단계 업그레이드(주간 리뷰/월간 백테스팅 업데이트/지속 학습). (`04_auto_execution_backtest/실행계획.md`)

**지금까지 확정된 것**
- 실전 자동매매(실계좌)는 아직 진행 안 함 → **모의투자/백테스팅까지만**
- 손절/익절 기준·매매 스타일은 백테스트 결과를 보고 결정하기로 함

**중요한 기술적 제약 발견**: 책이 예로 든 키움증권 OpenAPI+(구버전)는 Windows 32비트+ActiveX 기반이라 클라우드/리눅스 환경에서 실행 불가. 지속적 자동화를 위해 **한국투자증권(KIS) Developers API**(REST 기반, 모의투자 지원)로 대체 추천. 계좌 개설+API 키 발급은 신준님이 직접 진행 필요.

**백테스팅은 증권사 API 없이 지금 바로 가능** — Yahoo Finance 등 무료 데이터로 시작.

**책이 방향만 주고 넘어간 디테일 (우리가 정해야 함)** — 기본값 제안 포함:

| 항목 | 기본값 제안 |
|---|---|
| 대상 종목 | 삼성전자 단일 (이후 확장) |
| 백테스트 기간 | 최근 3년 |
| In-sample/Out-of-sample | 앞 2년 튜닝 / 최근 1년 검증(1회만) |
| 데이터 주기 | 일봉 |
| 초기자본/포지션 사이징 | 1,000만원, 매매당 20% |
| 모멘텀 조건 | 20일 이평 상향 돌파 + 점수제 3점 이상 |
| 회귀 조건 | RSI 30 이하 진입, 50~60 청산 |
| 돌파 조건 | 20일 신고가 + 거래량 150% 이상 |
| 손절/익절 후보 | 고정(-3%/+6%) / 트레일링(5%) / ATR×2 — 3안 동시 비교 |
| 수수료/세금 | 매매수수료 0.015% + 매도세 0.15% |
| 성과 지표 | 총수익률, 승률, 손익비, MDD, 코스피 대비 초과수익 |

**아직 결론 안 난 것 / 다음에 정해야 할 것**
- 위 표의 기본값을 그대로 쓸지 조정할지 → 확정 후 백테스트 스크립트 실행
- 백테스트 결과 보고 매매 스타일 1개 확정 + 손절/익절 기준 확정
- KIS 모의투자 API 신청·연동 (신준님 액션)
- 주간 리뷰 / 월간 백테스팅 업데이트 스케줄 작업 등록 (시스템 자리 잡은 후)
